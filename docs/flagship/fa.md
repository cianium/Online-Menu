## تجربه‌ای تازه برای رستوران

رامن منوی دیجیتال موبایل‌محور و محیط مدیریت رستوران است. مهمان کاتالوگ تصویری را مرور می‌کند و تیم رستوران محصولات، دسته‌ها و قیمت‌ها را مدیریت می‌کند. فارسی و عربی راست‌چین و انگلیسی و ترکی چپ‌چین هستند. سفارش QR، عملیات آشپزخانه و پرداخت شعبه در حالت متصل جدا از Demo مستقل‌اند.

## شروع Demo

با Git و Node.js نسخه ۲۲ یا بالاتر، دستورات زیر را اجرا کنید.

</div>

```bash
git clone https://github.com/cianium/Online-Menu.git
cd Online-Menu
npm run demo
```

<div dir="rtl">

[منوی مهمان](http://127.0.0.1:8765/) و [پنل مدیریت](http://127.0.0.1:8765/admin/) را در یک پروفایل مرورگر باز کنید. دیتابیس، حساب ابری و کلید API لازم نیست. برای توقف سرور Ctrl+C را بزنید.

## راهنمای مهمان

۱. زبان را انتخاب و دسته‌بندی‌ها را مرور کنید.
۲. غذا را جست‌وجو کنید، فیلترها و جزئیات محصول را ببینید.
۳. علاقه‌مندی و سبد را بررسی کنید؛ Demo سفارش و پرداخت واقعی ندارد.
۴. در رستوران متصل، QR امضاشده میز را باز کنید و مراحل در دسترس سفارش و پرداخت را دنبال کنید. وضعیت مبهم پرداخت را از کارکنان پیگیری کنید.

## راهنمای مدیر

۱. پنل را باز و نشان حالت Demo را بررسی کنید.
۲. در محصولات یک غذای نمونه بسازید: دسته، نام و قیمت را وارد و ذخیره کنید.
۳. دسته‌بندی‌ها و تنظیمات رستوران را بررسی کنید؛ فقط داده نمونه وارد کنید.
۴. به تب مشتری برگردید، تغییر کاتالوگ را ببینید و هر دو تب را Reload کنید.
۵. برای ارائه تمیز از پروفایل جداگانه استفاده کنید یا داده سایت همین origin را پاک کنید؛ این کار تغییرات محلی را حذف می‌کند.

## عملیات متصل

در محیط جداگانه و پیکربندی‌شده، کارکنان مجاز می‌توانند QR شعبه و میز، صف سفارش و نمایشگر آشپزخانه را مدیریت کنند. تنظیم واحد پول، میز و feature flag شعبه ضروری است. پرداخت به Merchant ID و تأیید callback در Sandbox نیاز دارد. پاسخ مرورگر به‌تنهایی سند پرداخت نیست.

## محدودیت و گام بعدی

تغییرات Demo فقط در همان مرورگر و origin ذخیره می‌شود؛ احراز هویت واقعی، دیتابیس مشترک، ارسال سفارش و پرداخت واقعی وجود ندارد. ممکن است فونت Google درخواست شود و در نبود شبکه از فونت جایگزین استفاده شود. اطلاعات واقعی مشتری یا رمز وارد نکنید. رستوران ناشناخته صریح نباید کاتالوگ نمونه دریافت کند.

برای ارائه خصوصی آینده روی VPS، با دستور <code>npm run demo:export</code> بسته بسازید، SHA-256 را بررسی کنید و HTTPS و کنترل دسترسی هر دو رابط را تنظیم کنید. [راهنمای Demo](../DEMO_LOCAL.md)، [راهنمای VPS](../VPS_DEMO_FA.md) و [شرایط استقرار](../DEPLOY_VQ3_FA.md) را بخوانید. این راهنما تأیید عملکرد Production نیست.
