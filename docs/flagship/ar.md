## تجربة رقمية للمطاعم

رامن قائمة طعام رقمية مصممة للهواتف ومساحة لإدارة المطعم. يتصفح الضيف قائمة مصورة، ويدير الفريق المنتجات والفئات والأسعار. تدعم العربية والفارسية الاتجاه من اليمين إلى اليسار، والإنجليزية والتركية الاتجاه المعاكس. الطلب عبر QR وشاشة المطبخ والدفع للفرع تتطلب وضعاً متصلاً منفصلاً عن النسخة التجريبية.

## تشغيل النسخة التجريبية

ثبّت Git وNode.js بالإصدار 22 أو أحدث، ثم نفّذ:

</div>

```bash
git clone https://github.com/cianium/Online-Menu.git
cd Online-Menu
npm run demo
```

<div dir="rtl">

افتح [قائمة الضيف](http://127.0.0.1:8765/) و[لوحة الإدارة](http://127.0.0.1:8765/admin/) في ملف تعريف المتصفح نفسه. لا تحتاج إلى قاعدة بيانات أو حساب سحابي أو مفتاح API. لإيقاف الخادم المحلي اضغط Ctrl+C.

## دليل الضيف

١. اختر اللغة وتصفح الفئات.
٢. ابحث عن طبق، واستخدم الفلاتر وافتح تفاصيل المنتج.
٣. جرّب المفضلة والسلة؛ لا تتوقع طلباً أو دفعاً حقيقياً في العرض التجريبي.
٤. في مطعم مهيأ، استخدم رمز QR الموقّع للطاولة واتبع خطوات الطلب والدفع المتاحة. استفسر من الموظفين إذا كانت حالة الدفع غير واضحة.

## دليل المدير

١. افتح لوحة الإدارة وتحقق من مؤشر الوضع التجريبي.
٢. من المنتجات أضف طبقاً تجريبياً: اختر الفئة وأدخل الاسم والسعر ثم احفظ.
٣. راجع الفئات وإعدادات المطعم، واستخدم بيانات تجريبية فقط.
٤. ارجع إلى تبويب الضيف، وتحقق من تحديث القائمة، ثم أعد تحميل التبويبين.
٥. للحصول على عرض نظيف، استخدم ملف تعريف متصفح منفصلاً أو امسح بيانات الموقع لهذا العنوان؛ سيؤدي ذلك إلى حذف التعديلات المحلية.

## التشغيل المتصل

في بيئة مهيأة بشكل منفصل، يستطيع الموظفون المخولون إدارة روابط QR للفروع والطاولات وقائمة الطلبات وشاشة المطبخ. يلزم ضبط العملة والطاولات وتفعيل خصائص الفرع. يتطلب الدفع حساب تاجر مهيأ والتحقق من استجابة مزود الدفع في بيئة الاختبار. لا تعد استجابة المتصفح وحدها إثباتاً للدفع.

## الحدود والخطوة التالية

تبقى تغييرات العرض في المتصفح والعنوان نفسيهما؛ لا توجد مصادقة حقيقية أو قاعدة بيانات مشتركة أو تنفيذ طلبات أو دفع فعلي. قد تُطلب خطوط Google وتستخدم خطوط بديلة عند تعذر الوصول. لا تدخل بيانات العملاء أو كلمات المرور. يجب ألا يعرض عنوان مطعم مجهول محدد صراحة قائمة تجريبية بديلة.

لعرض خاص على VPS مستقبلاً، استخدم <code>npm run demo:export</code>، وتحقق من بصمات SHA-256، واضبط HTTPS والتحكم في الوصول للواجهتين. راجع [التشغيل المحلي](../DEMO_LOCAL.md) و[دليل VPS بالفارسية](../VPS_DEMO_FA.md) و[شروط النشر بالفارسية](../DEPLOY_VQ3_FA.md). لا يثبت هذا الدليل جاهزية الإنتاج.
