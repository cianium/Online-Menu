# ROMANO Version Comparison

| Version | Role | Important characteristics |
|---|---|---|
| Rv4.5 ADMIN FULL UX | UI-heavy admin branch | Strong admin workspace and early language layer; older runtime baseline |
| Rv4.5.1 DEBUGGED | hardening branch | incremental fixes over Rv4.5; still older than Rv4.6 |
| Rv4.6 COMPLETE MERGED | integration baseline | Rv4.6 merged customer/admin implementation; customer-side i18n foundation |
| Rv4.6 COMPLETE TRANSLATED | canonical baseline | Rv4.6 runtime + full customer/admin four-language presentation layer + release QA docs |
| Final Restaurant Menu | packaged runtime copy | Same 45 common runtime files as Rv4.6 COMPLETE TRANSLATED, without the three release docs |

## Selection
Use **Rv4.6 COMPLETE TRANSLATED** as the engineering baseline. The prepared package in this release is a corrected derivative of that baseline.
