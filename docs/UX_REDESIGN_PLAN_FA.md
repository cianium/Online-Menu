## نخستین چرخه پیاده‌سازی — ۱۱.۱ و بخشی از ۱۲.۱/۱۲.۲

- افزودن `css/interaction-system.css` به هر دو رابط و cache manifest نسخه عمومی؛ حفظ worker بدون cache در export خصوصی. هدف لمسی و رفتار کاهش حرکت.
- ترتیب فیزیکی نوار پایین مشتری در DOM و CSS، فعال‌سازی براساس اسکرول، حفظ fragment navigation و back/forward مرورگر. پنل native dialog ارتباط با escape، focus restore، متن چهارزبانه و نمایش فقط اطلاعات رستوران فعلی. اطلاعات نمونه Demo لینک تماس فعال ندارند؛ وضعیت loading/unavailable به داده نمونه باز نمی‌گردد. مسیریابی، چت و رضایت هنوز پیاده نشده‌اند.
- کاهش ارتفاع/عنوان Hero در موبایل و فشرده‌تر کردن ردیف سبد با کنترل‌های ۴۴ پیکسلی؛ بازطراحی کامل کارت‌ها و Hero نیاز به بررسی بصری بعدی دارد.
- هدر مدیریت فشرده و آیکن‌محور؛ خروج به منوی کناری منتقل شد؛ دکمه افزودن موجود صفحه محصولات حفظ شد. هشدار Demo زیر هدر به details جمع‌شونده تبدیل شد و وضعیت ذخیره در strip جدا حفظ شد. منوی پایین مدیریت هنوز ساخته نشده؛ باید همراه صفحه واقعی باشگاه و router تکمیل شود.
- ۲ تست جدید Node و ۳ سناریوی مرورگری جدید به مجموعه موجود اضافه شد. `npm run qa` روی کپی کامل موفق: ۵۹ + ۲۰ = ۷۹ تست، Static Audit بدون خطا و هشدار. `node --check` فایل‌های تست مرورگری موفق. خروجی Demo شامل ۶۹ فایل عمومی با SHA-256 معتبر. HTTP محلی Customer/Admin/CSS پاسخ موفق داد. اجرای Chromium روی localhost با `ERR_BLOCKED_BY_ADMINISTRATOR` متوقف شد؛ نتیجه بصری، آزمون تعامل و ریسپانسیو جدید هنوز تأیید نشده‌اند.
- تغییرات در GitHub یا Pages ثبت نشده‌اند. PR #24 به مستندات اختصاص دارد و بدون تغییر باقی ماند. سه شکست سرویس‌های قدیمی آنلاین خارج از scope فعلی Demo هستند.

## ملاحظات ممیزی بعدی

کد فعلی `paymentReturn()` در `js/commerce.js` پیام نتیجه را از query string می‌سازد؛ قبل از فعال‌سازی عملیات واقعی، منبع معتبر سمت سرور و کنترل نتیجه پرداخت باید ممیزی شود (یافته بازبینی کد، نه اثبات شکست تراکنش). همچنین GitHub Pages پنل Demo را عمومی نشان می‌دهد و auth عملیاتی ندارد؛ برای داده واقعی مناسب نیست. هر تنظیمات حساس و API واقعی نیاز به بررسی جداگانه دارد.
