# R12 — standalone revenue analytics
The dashboard reports the value of saved local sample orders, never verified revenue. Today (hourly), last 7/30 days (daily), trailing 365 days (calendar month buckets, partial boundary months) use browser-local dates. Compare with immediately preceding equal number of local days, no percentage if baseline is zero. Currency selector isolates currencies; new sample orders snapshot catalog currency (IRR catalog values are authored/displayed as IRT). Older records missing a currency remain in history but are excluded from analytics, with a notice. Future timestamps excluded, duplicate order IDs and corrupt storage fail closed. CSV contains aggregate dates, currency, totals, counts, averages; no PII. Connected mode deliberately shows unavailable because operational order lists are capped and not authoritative payment history. No real revenue or payment service is implemented. Four locales, native controls, accessible data table, no dependencies. No merge/deploy. Exact-head QA required.
