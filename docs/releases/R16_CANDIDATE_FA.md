## شاخه‌ها و نسخه

- `main`: تنها شاخه رسمی کد منبع؛ مبنای پیشین R13 برابر `9876790927dc752a14d83727c8bad16176e8e8da` است.
- `fix/r16-release-consolidation`: کاندید یکپارچه R14 تا R16، [PR #28](https://github.com/cianium/Online-Menu/pull/28). SHA دقیق نسخه را از HEAD و خروجی CI بخوانید.
- `ux/r14-experience-hardening`: تاریخچه R15 که به‌طور کامل در شاخه کاندید قرار دارد.
- `feat/r16-standalone-branch-foundation`: نمونه معماری قدیمی و ناسازگار؛ جایگزین اجرای فعلی نشود.
- `pages-demo`: خروجی انتشار مستقل؛ نه شاخه توسعه و نه تضمین تطابق با HEAD. هویت منبع در VERSION.json ثبت می‌شود.

R16 نام مرحله مهندسی است؛ شماره بسته ریشه 3.0.0 (vq.3) است. هیچ تگ یا Release جدیدی با این یادداشت ایجاد نمی‌شود.

## امکانات نسخه مستقل

- ثبت عضو نمونه با نام و شماره، تاریخچه سفارش و ورود مدیر آزمایشی.
- کاتالوگ، تنظیم میز و QR محلی، ساخت و تغییر نام شعبه.
- فعال و غیرفعال کردن شعبه‌های غیر اصلی از محیط شعبه اصلی، بدون حذف سوابق.
- گزارش مبلغ سفارش‌های نمونه و تعداد مشتریان و اقلام پرفروش؛ این گزارش درآمد یا پرداخت واقعی نیست.
- پشتیبان نسخه‌دار از فهرست شعب، منو، اعضا، سفارش‌ها، پیش‌نویس وفاداری، نظرات و امتیازهای قدیمی؛ شامل شعب غیرفعال.
- بازیابی فقط در محیط خالی مرورگر؛ فایل شامل اطلاعات شخصی است. از داده ساختگی استفاده کنید و سایر تب‌ها را ببندید. این سازوکار تراکنش اتمی چندتب یا پایگاه داده مشترک نیست.
- رابط فارسی، عربی، انگلیسی و ترکی.

## ساخت و انتشار

```sh
npm run qa
npm run qa:syntax
node qa/build-commercial-demo.mjs /absolute/path/to/new-ramen-demo
```

راهنمای اجرا و checksum: [COMMERCIAL_DEMO_GUIDE](../COMMERCIAL_DEMO_GUIDE.md). پیش از انتشار، شش Workflow را روی SHA دقیق کاندید بررسی کنید. Merge و انتشار به تأیید صریح مالک نیاز دارند. برای بازگشت از SHA معتبر قبلی یا بسته ثبت‌شده استفاده کنید؛ تاریخچه را بازنویسی نکنید.

## محدودیت‌های باقی‌مانده

تست دستی کنتراست، دستگاه واقعی و تأیید اختیاری سرویس‌های متصل و پرداخت واقعی هنوز جداگانه لازم است. نسخه مستقل حساب واقعی، احراز هویت امن سمت سرور یا QR مشترک میان دستگاه‌ها ارائه نمی‌کند. فراداده تاریخی GitHub Release و About/Topics موضوع [Issue #10](https://github.com/cianium/Online-Menu/issues/10) است؛ بسته شدن آن منوط به اعمال واقعی تغییرات مدیریتی است.
