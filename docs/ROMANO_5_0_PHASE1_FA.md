# ROMANO 5.0 — مرحله اول: مقایسه، انتخاب مبنا و گیت انتشار

تاریخ: ۲۰۲۶-۱۰-۱۵

## مقایسه مستقیم دو ZIP

- 4.9.0-customer(1): ۱۱۴ مسیر فایل در آرشیو.
- 4.9.1-mobile-review: ۱۱۹ مسیر فایل در آرشیو.
- تمام مسیرهای 4.9.0 در 4.9.1 وجود دارند؛ پنج مسیر جدید افزوده شده است.
- تغییرات کد 4.9.1 شامل اصلاحات فرم موبایل ادمین، سیاست مجوز snapshot، CSRF، ترجمه، امتیاز عددی و fallback آفلاین است. فایل‌های مستندات و تصاویر QA نیز تغییر کرده‌اند.
- انتخاب: **4.9.1**، چون اصلاحات مشخص دارد و چیزی از ساختار نسخه قدیمی حذف نکرده است. برتری آن به معنی بی‌نقص بودن نیست.

## تغییر این مرحله

- افزودن `qa/production-preflight.mjs`: بررسی فقط‌خواندنی تنظیمات مهم انتشار؛ بدون چاپ credential و بدون اتصال به دیتابیس.
- افزودن دستور `npm run qa:production`.
- بدون تغییر UI مشتری، ادمین، API، مدل داده، ترجمه‌ها یا فایل‌های تصویری.

## آزمون‌ها

- `npm run qa`: موفق؛ ۲۷ تست Node، به‌علاوه syntax/static.
- `npm run qa:production`: برای محیط بدون پیکربندی production انتظار شکست دارد؛ این رفتار درست است، نه خرابی پروژه.
- اجرای واقعی PostgreSQL، تست مرورگر، تست دستگاه موبایل، تست نفوذ و انتشار انجام نشده‌اند.

## اولویت مرحله بعد

1. آزمون عملی backend با PostgreSQL و نقش‌های viewer/editor/manager، به‌ویژه جداسازی رستوران‌ها.
2. جلوگیری از بازنویسی هم‌زمان اطلاعات با revision و پاسخ 409.
3. بهبود هم‌زمان Customer/Admin بدون بازسازی قابلیت‌های موجود؛ چهار زبان و RTL/LTR حفظ شوند.
4. پشتیبان‌گیری، بازیابی، پایش خطا و فرایند انتشار قابل تکرار.

**هشدار:** preflight جایگزین ممیزی امنیتی یا تأیید Production نیست.
